# Copilot Instructions for Eshop

Use the workspace custom agent `eshop-assistant` when working in this repository.

This repo is an Angular-based storefront project. When editing code or documentation here, the preferred behavior is:

- focus on Angular/TypeScript/HTML/CSS and repository-specific configuration
- use workspace file inspection tools first (`read_file`, `grep_search`, `replace_string_in_file`, etc.)
- avoid broad or noisy edits outside the repository scope
- keep responses concise, factual, and task-focused

The workspace also includes `.agent.md` for the agent's custom behavior and scope.
